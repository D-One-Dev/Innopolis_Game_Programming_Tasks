# Тестовые данные (ДЗ10)

Каждый файл `*.txt` в этой папке — входные данные для одного запуска
соответствующей программы:

```sh
./task1 < tests/task1_basic.txt
./task2 < tests/task2_russian.txt
./task3 < tests/task3_basic.txt
```

Прогнать все тесты сразу: `bash tests/run_tests.sh`.
Ожидаемые результаты приведены в таблицах ниже; нумерация тестов
совпадает с выводом скрипта.

## Задача 1 — сортировка по убыванию и удаление дубликатов

| Файл | Что проверяет | Ожидаемый результат |
|---|---|---|
| `task1_basic.txt` | обычный набор с дубликатами | `Result: 9 8 7 5 3 1`, `Elements deleted: 6` |
| `task1_duplicates.txt` | все элементы одинаковые | `Result: 2`, `Elements deleted: 9` |
| `task1_negatives.txt` | отрицательные числа и нули | `Result: 12 7 0 -1 -4`, `Elements deleted: 3` |
| `task1_sorted.txt` | уже упорядоченный набор без дубликатов | `Result: 6 5 4 3 2 1`, `Elements deleted: 0` |
| `task1_empty.txt` | пустой набор (N = 0) | пустой `Result:`, `Elements deleted: 0` |

## Задача 2 — частота слов

| Файл | Что проверяет | Ожидаемый результат |

| `task2_english.txt` | английский текст, регистр и пунктуация | `Unique words: 12`; топ-1 `the — 4`; 8 слов-одиночек |
| `task2_russian.txt` | русский текст (UTF-8), разный регистр | `Unique words: 11`; топ-1 `кот — 4`; 9 слов-одиночек |

| `task2_digits.txt` | числа считаются словами | `Unique words: 5`; топ-1 `room — 3`; одиночные: `102`, `again`, `and` |
| `task2_punctuation.txt` | только знаки препинания | `Unique words: 0`, пустые разделы |

| Файл | Что проверяет | Ожидаемый результат |
